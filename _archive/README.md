# Archived GASENOS pages

The original GASENOS store pages were removed from the PARFS site and moved here so they can be
recovered if ever needed. Nothing in this folder is built or served (it is excluded from TypeScript
and ESLint). Safe to delete once you're sure you won't need it.

- `gasenos-pages/(store)/` — shop, categories, deals, new, about, help, membership, policies, search,
  cart, track-order, AI assistant, account (login/register/orders/…), plus earlier `.bak` backups.
- `gasenos-pages/(checkout)/` — checkout, success, payment-failed, test-payment.
- `gasenos-pages/*.tsx|ts` — the original root layout, 404, error page, sitemap and manifest.
